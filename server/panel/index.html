Подписки

Подписка объединяет подключения на разных VDS. При включённом координаторе используется общий лимит; каждую учётную запись удалённого узла нужно привязать к ID подписки.

Общий учёт требует quota.coordinator=true на главном сервере и настройки quota на каждом VDS. Уже созданный журнал учёта нельзя удалить снятием флажка.

Новая подписка

HTTPS только для подписок

Публичный HTTPS-слушатель не содержит админскую панель и не выдаёт QUIC CID. ACME использует HTTP-01 на порту 80. Продление выполняется заранее по фактическому сроку сертификата.

После изменения настроек слушателя нужен штатный перезапуск сервера. Уже выпущенные сертификаты ACME продлеваются без перезапуска VPN.

Узлы общего учёта

Эти ключи разрешают только расход квоты указанных подписок, не управление VPN. Выданный ключ показывается один раз. На удалённом VDS сохраните его в отдельном защищённом файле.
