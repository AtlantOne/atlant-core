# Atlant и Xray: ограниченный канал и отзывчивость

24 октября 2026. Полная матрица: 60 успешных окон измерения, 0 ошибок,
584.56 MiB CRC-подтверждённых данных, 1997 завершённых echo-проб.

Канал 20 Мбит/с в каждом направлении. Clean: без заданных задержек/потерь;
rtt50-loss1: задержка 25 мс + jitter 2 мс и потери 1% в каждом направлении;
rtt100-loss3: задержка 50 мс + jitter 5 мс и потери 3% в каждом направлении.
Очередь 256 пакетов, MTU 1500, GSO/GRO/TSO off только на временных veth.
Netem действует на forwarded tunnel-пакеты, а не egress TCP-отправителя.

Настоящие клиенты и серверы в двух отдельных child network namespaces.
Третий временный namespace содержит маршрутизатор, RAM-цель и локальный
TLS/HTTP2-донор для Xray REALITY. Внешнего Интернета нет. Узлы используют одно SNI.
Сборки Atlant те же, что в RAM-тесте; Xray 26.3.27. Для расширения сравнения
изменён только стенд, не код VPN. На основном хосте маршруты/DNS/VPN не менялись.

Каждое окно — 8 секунд, два повтора каждого направления, новые процессы/сессии.
4 bulk-потока + отдельный echo-поток. Pipeline: до 16 неподтверждённых блоков
64 KiB на поток. Учёт только после CRC/ACK; конечные незавершённые блоки не входят.
Внутреннего TLS нет. Защитные настройки Atlant включены, pacing не отключён.
TCP mux=false: независимые внешние TCP-соединения; QUIC использует общую сессию.
Это поведение данных конфигураций, не равенство числа congestion controllers.

Значения в таблицах — медианы двух повторов. Для задержки это **медиана p95
отдельных окон**, а не p95 объединённых проб и не доверительный интервал.
Пограничные таймауты при завершении окна сохранены в CSV: всего 37.
Ранние таймауты считаются ошибками и не исключаются из удачных серий молча.
Во всех строках есть завершённые echo-пробы; число проб сохранено отдельно.
