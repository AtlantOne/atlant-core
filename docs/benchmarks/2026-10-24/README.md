# Материалы измерений Atlant и Xray

Отчёты и исходные таблицы к статье. Текстовые файлы и CSV открываются прямо
на GitHub; для просмотра не требуется скачивать приложение к релизу.

| Материал | Содержание |
|---|---|
| [Отчёт локальной пропускной способности](ram-report.md) | Методика, диапазоны повторов и результаты TCP/XHTTP/QUIC и Xray |
| [Все 144 измерения](ram-samples.csv) | CSV без сведений о модели компьютера и ресурсных диагностик CPU/RSS |
| [Отчёт ограниченного канала](channel-report.md) | Канал 20 Мбит/с, задержки, потери и отклик под нагрузкой |
| [Все 60 окон канальных испытаний](channel-samples.csv) | Исходные результаты обоих направлений |
| [1997 echo-проб](channel-pings.csv) | Время отправки относительно начала нагрузки и время ответа |
| [Восемь окон XHTTP до/после](xhttp-before-after.csv) | Отдельная серия доработки распределения соединений |
| [Хеши реализации](implementation-sha256.json) | SHA-256 исходных файлов доработки |
| [Воспроизведение измерений](REPRODUCE.md) | Инструкция и ссылка на архив исходников стенда |

Стенд — слабый ноутбук; точная конфигурация оборудования не публикуется.
Числовые результаты скорости, задержки и проверенного объёма данных сохранены.
Базовая серия относится к первоначальной реализации, серия XHTTP до/после —
к обновлению preview.2. Это исторические измерения, а не новые результаты
каждого последующего релиза.
