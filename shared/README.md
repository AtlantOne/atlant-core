# Общий протокольный код

`auth` — взаимное подтверждение PSK пользователя HMAC-SHA256, привязанное
к TLS 1.3 exporter. Разные метки client/server предотвращают отражение proof;
exporter связывает proof с конкретной TLS-сессией. Полезные данные разрешены
только после обеих проверок. Ключ должен быть случайным 32-байтовым секретом.

`quicpeer` — адаптер аутентификации к quic-go с таймаутом и отменой, а также
единый 20-байтовый генератор/проверка Connection ID с nonce-счётчиком.
CID — предварительный классификатор пакетов; он не заменяет взаимную аутентификацию.

`wire` — полная запись в поток и единое кодирование/чтение заголовка QUIC.
`settings` — проверка профиля и нормализация границ padding до wire-формата uint16.

Локальные тесты: `go test -race ./...`.
Fuzz-проверка парсера: `go test ./wire -run '^$' -fuzz FuzzReadQUICHeader -fuzztime 10s`.

Проверка QUIC включает реальные TLS/QUIC v1/v2 соединения на loopback,
аутентификацию, пользовательский поток и датаграмму. Проверки не обращаются
к внешним серверам и не меняют системные маршруты.

Это собственное расширение протокола, использующее стандартные примитивы;
тесты не являются независимым криптографическим аудитом.
